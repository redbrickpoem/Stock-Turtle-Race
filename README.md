# 🐢 Stock Turtle Race

A fun and visual Python project that turns stock price data into a turtle race!

This project uses:
- 📈 Real historical stock prices from Yahoo Finance (`yfinance`)
- 🐢 Python's built-in `turtle` module to animate each stock as a racing turtle
- 🎨 OOP design for clean code and reusability

Each turtle moves forward based on daily stock price changes from Jan–Mar 2025.
